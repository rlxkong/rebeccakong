PointView

Computer VisionYOLOv8

An AI-based application that analyzes tennis matches by tracking the players and the ball with YOLOv8.

Built during the Entrepreneurship Studio Program at Harvey Mudd College as a computer-vision tennis analysis platform using object detection and automated match processing. Developed PointView, which uses computer vision and machine learning to analyze tennis matches by tracking the players and the ball with YOLOv8. Trained a customized YOLOv8 object-detection model for tennis footage, managing the full pipeline from manual data collection and labeling to dataset preparation, model training, and evaluation. Combined player detection, ball tracking, and coordinate mapping to transform raw match footage into a birds-eye view of on-court activity.
